# Страница «Проекты»

Учебное SPA на Vite + React + TypeScript: список проектов с поиском, созданием через модалку и сохранением в `localStorage`.

## Что делает страница

- Показывает список проектов (название, описание, дата, статус)
- Ищет по названию и описанию (регистронезависимо, debounce 200 мс)
- Создаёт проект через форму с валидацией
- Восстанавливает данные после перезагрузки вкладки
- При первом запуске подтягивает 5 мок-проектов из `src/data/mockProjects.ts`

## Запуск локально

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`).

Сборка:

```bash
npm run build
npm run preview
```

## Ручной чек-лист

- [ ] При первом открытии видны 5 мок-проектов
- [ ] После F5 / обновления вкладки список не пропадает
- [ ] Поиск фильтрует по названию и описанию без учёта регистра
- [ ] При пустом результате поиска — «Ничего не найдено»
- [ ] «Создать проект» открывает модалку; Esc и клик по фону закрывают её
- [ ] Пустое / короткое название показывает ошибку под полем
- [ ] Новый проект сразу появляется вверху списка и остаётся после F5
- [ ] Desktop (>640px): поиск слева, кнопка справа в одной строке
- [ ] Mobile (≤640px, проверьте 320px): поиск и кнопка в колонку на всю ширину, без перекрытия
- [ ] Модалка на телефоне помещается в экран, форма скроллится

## Вероятные ошибки и как они предотвращены

| Риск | Как предотвращён |
|------|------------------|
| Потеря данных при F5 | `useLocalStorage` пишет в `localStorage` при каждом изменении и читает при инициализации |
| Пустой localStorage при первом запуске | Если ключа нет — подставляются `mockProjects` и сразу сохраняются |
| Битый JSON в localStorage | `try/catch` при чтении → откат к начальному значению |
| Переполнение квоты localStorage | `try/catch` при записи → UI продолжает работать в памяти текущей сессии |
| Бесконечный ререндер с localStorage | Запись только в `useEffect([key, storedValue])`, без `setState` внутри эффекта чтения |
| Перекрытие поиска и кнопки на 320px | Mobile-first: `flex-direction: column`, `width: 100%`, `min-width: 0`; на ≥641px — ряд |
| `position: fixed` у кнопки/поиска | Не используется; fixed только у backdrop модалки |
| XSS через HTML в названии/описании | Текст рендерится через `{project.name}` / React-экранирование; `dangerouslySetInnerHTML` не используется |
| Модалка «ломает» скролл страницы | При открытии `overflow: hidden` на `body`, при закрытии восстанавливается |
| Двойной submit / невалидные данные | `preventDefault` + валидация до вызова `onSubmit` |
| Недоступная форма | `label` у полей, `aria-invalid` / `aria-describedby`, закрытие по Esc и клику по фону, `aria-label` у кнопки закрытия |
